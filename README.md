Entry for the make.fun bounty [Notes From a Passive-Aggressive Fridge](https://make.fun/bounty/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7).

A Python program that writes one funny passive-aggressive note a smart
fridge leaves for its owner into `/output/entry.txt`:

> The ice maker made 214 cubes this week. You used three. The other 211 are judging you too.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
